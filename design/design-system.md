# 루원365한의원 Design System

Zapier 브랜드 시스템에서 영감을 받아 의료/한의원 맥락에 맞게 재해석한 디자인 시스템입니다.
따뜻한 크림 캔버스와 깊은 커피 잉크를 기반으로, 단일 포인트 컬러(Teal)를 사용합니다.

---

## Overview

따뜻한 크림 캔버스(`#fffefb`)와 깊은 커피 잉크(`#201515`)를 페어링하고, 단일 포인트 컬러로 신뢰감 있는 Teal(`#0d9488`)을 사용합니다. 순수 화이트가 아닌 약간 크림빛이 도는 캔버스 온도가 이 디자인의 핵심 브랜드 시그니처입니다.

타이포그래피는 Pretendard를 전체에 사용합니다. 히어로 헤드라인은 `weight 700`, 서브디스플레이는 `weight 600`, 본문은 `weight 400`.

카드와 버튼 모두 `border-radius: 12px` (`rounded-xl`)을 사용합니다. 알약형도 아니고 직각도 아닌, 브랜드의 중간 위치 시그니처입니다.

**주요 특성:**
- 단일 포인트 컬러: Teal(`#0d9488`) — 모든 주요 CTA의 컬러 시그니처
- 따뜻한 크림 캔버스(`#fffefb`) — 순수 화이트가 아님. 온도가 브랜드 보이스
- 깊은 커피 잉크(`#201515`) — 순수 블랙이 아님. 온기가 텍스트까지 이어짐
- 12px 버튼·카드 반경 — 브랜드의 미들 라디우스 시그니처
- 모든 중립 컬러에 온기가 담김 — 차가운 순수 회색은 사용하지 않음

## Typography

### 폰트 패밀리
- **Pretendard** — 히어로 헤드라인(700), 서브디스플레이(600), 본문(400), 버튼(600/700), 아이브로우(500)
- 한국어 타이포그래피에 최적화된 단일 페이스 시스템

### 계층 구조

| 토큰 | 크기 | 굵기 | 라인헤이트 | 자간 | 용도 |
|---|---|---|---|---|---|
| `display-xl` | 48px | 700 | 1.1 | -0.5px | 히어로 헤드라인 |
| `display-lg` | 36px | 700 | 1.2 | -0.3px | 서브히어로 디스플레이 |
| `display-md` | 28px | 700 | 1.3 | 0 | 섹션 헤드라인 |
| `display-sub` | 22px | 600 | 1.4 | -0.3px | 카드 타이틀 |
| `body-lg` | 18px | 400 | 1.7 | -0.1px | 리드 단락 |
| `body-md` | 16px | 400 | 1.7 | 0 | 기본 본문 |
| `body-sm` | 14px | 400 | 1.6 | 0 | 보조 본문 |
| `caption` | 12px | 400 | 1.5 | 0 | 세부 주석 |
| `eyebrow` | 12px | 500 | 1.0 | 1.5px | 대문자 아이브로우 (섹션 상단 레이블) |
| `button-md` | 16px | 600 | 1 | 0 | 주요 버튼 레이블 |

### 원칙
- **아이브로우는 영문 대문자 또는 한국어 소문자**로 사용. `letter-spacing: 1.5px`.
- **제목은 문장형(첫 글자만 대문자)으로**. 전체 대문자 헤드라인 사용 금지.
- **Pretendard 700을 히어로 전용으로**. 나머지는 600 이하.

## Layout

### 스페이싱 시스템
- **기본 단위**: 4px
- `xs`: 4px · `sm`: 8px · `md`: 12px · `lg`: 16px · `xl`: 24px · `2xl`: 32px · `3xl`: 48px · `4xl`: 64px
- **섹션 패딩**: 상/하 64px (`py-16`)
- **카드 내부**: 24px (`p-6`)

### 그리드 & 컨테이너
- 마케팅 컨테이너: 최대 1280px, 중앙 정렬
- 히어로: 데스크탑에서 텍스트 중앙 또는 좌측, 모바일에서 스택
- 서비스 그리드: 데스크탑 3컬럼, 태블릿 2컬럼, 모바일 1컬럼

### 반응형
| 브레이크포인트 | 너비 | 변화 |
|---|---|---|
| 모바일 | < 640px | 1컬럼, 햄버거 네비 |
| 태블릿 | 640–1023px | 2컬럼 |
| 데스크탑 | ≥ 1024px | 3컬럼, 히어로 풀 그리드 |

## Elevation & Depth

| 레벨 | 처리 방식 | 용도 |
|---|---|---|
| Level 0 — Flat | 그림자 없음, 보더 없음 | 히어로 기본 |
| Level 1 — Hairline | `1px solid rgba(32,21,21,0.08)` | 카드 아웃라인, 아웃라인 버튼 |
| Level 2 — Soft Card | `canvas-soft` 크림 배경 | 기본 콘텐츠 카드 — 서피스 대비로 elevation 표현 |
| Level 3 — Shadow | `0 2px 16px rgba(32,21,21,0.06)` | 모달, 드롭다운 |

## Components

### 버튼

**`button-primary`** — Teal CTA 버튼
- 배경 `#0d9488`, 텍스트 흰색, 12px 반경, 패딩 `12px 24px`

**`button-secondary`** — 다크 커피 잉크 버튼
- 배경 `#201515`, 텍스트 흰색, 동일 형태

**`button-outline`** — 아웃라인 버튼
- 배경 `canvas`, 텍스트 `ink`, `1px solid ink`, 동일 형태

### 카드

**`card-default`** — 크림 소프트 콘텐츠 카드
- 배경 `#f8f4f0`, 텍스트 `ink`, 패딩 24px, 12px 반경

**`card-dark`** — 다크 커피 카드 (강조용)
- 배경 `#201515`, 텍스트 흰색, 패딩 24px, 12px 반경

### 네비게이션

**`nav-bar`** — 고정 상단 네비
- 배경 `canvas(#fffefb)`, `1px` 하단 보더, 패딩 `12px 24px`

**`footer`** — 다크 커피 푸터
- 배경 `ink(#201515)`, 텍스트 크림 소프트, 패딩 `64px 24px`

### 시그니처 컴포넌트

**`hero-band`** — 크림 히어로 밴드
- 배경 `canvas(#fffefb)`, 텍스트 `ink`, 아이브로우 → 히어로 헤드라인 → 서브텍스트 → CTA

**`eyebrow-label`** — 섹션 상단 소형 레이블
- `font-size: 12px`, `font-weight: 500`, `letter-spacing: 1.5px`, Teal 컬러 또는 mute 컬러

**`badge-pill`** — 인라인 카테고리 배지
- 배경 `primary-light(#ccfbf1)`, 텍스트 `primary-dark`, 9999px 반경

## Do's and Don'ts

### Do
- 모든 주요 CTA에 Teal(`#0d9488`)을 사용하세요. 단일 포인트 컬러가 신뢰 시그니처입니다.
- 캔버스를 따뜻하게 유지하세요 — `#fffefb` 크림, 순수 화이트 금지.
- 히어로 헤드라인을 Pretendard 700으로 설정하세요.
- 모든 버튼과 카드에 12px 반경을 사용하세요.
- 아이브로우 레이블로 섹션 계층을 시각화하세요.

### Don't
- 순수 화이트(`#ffffff`)로 캔버스를 교체하지 마세요. 온기가 브랜드입니다.
- 순수 블랙 텍스트를 사용하지 마세요. `#201515` 커피 잉크를 유지하세요.
- CTA를 알약형(pill)으로 렌더링하지 마세요. 12px 반경이 시그니처입니다.
- 두 번째 액센트 컬러를 추가하지 마세요. Teal + 크림 + 커피가 전체 팔레트입니다.
- 의료 광고 규정에 위배되는 표현(완치, 100% 보장, 최고 등)을 사용하지 마세요.
